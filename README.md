# Farhan Nasir Portfolio

Next.js portfolio (Mrityunjay-inspired design) with Farhan's content.

## Run

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Replace later

- Drop your real CV at `public/cv.pdf`
- Update social links in `src/data/site.ts`
- Update education in `src/data/education.ts`
- Replace blog posts in `src/data/blogs.ts`
- Send any new project images and they can be placed under `public/projects/<slug>/`
